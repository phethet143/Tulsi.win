# 🌿 Tulsi Win

**Tulsi Win** is a modern, responsive web-based gaming and prediction platform built with HTML, CSS, and JavaScript. It replicates popular entertainment and prediction app interfaces with smooth navigation, real-time interactive features, and a polished mobile-first design.

## ✨ Key Features

* **🎮 Win Go Game Room:** Multiple countdown timer modes (30s, 1Min, 3Min, 5Min), color betting (Green, Violet, Red), number selection (0-9), multipliers, Big/Small choices, and live history tracking.
* **🎡 Activity & Invite Wheel:** Interactive spinning wheel module with prize tracking, attendance bonuses, and first deposit offers.
* **💎 Promotion & Agency System:** Comprehensive agency dashboard featuring direct and team subordinate statistics, commission breakdowns, and invitation code sharing.
* **👤 User Profile & Wallet:** Secure user UID management, VIP levels, ARWallet integration, and quick transaction, deposit, and withdrawal history tabs.

## 🚀 Getting Started

1. Clone or download this repository.
2. Rename your main file to `index.html`.
3. Open `index.html` in any web browser or deploy it instantly via **GitHub Pages** or **Netlify**.
